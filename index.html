Cómo Obtener el Token

El token es necesario para crear una sala de Haxball:

  1. Abre haxball.com/headlesstoken
  2. Inicia sesión con tu cuenta
  3. Resuelve el captcha
  4. Copia el token (thr1.xxx...)
  5. Pégalo en el campo de token
⚠️ Importante
  • El token expira cada ~24 horas
  • Puedes usar el mismo token en todas las salas
